# Neovim Docker IDE

Полнофункциональная надстройка над Neovim в Docker-контейнере, предоставляющая IDE-подобный опыт для разработчиков, мигрирующих с JetBrains IDE (PHPStorm, WebStorm) на Vim/Neovim.

## Описание проекта

Данный проект представляет собой готовое к использованию окружение разработки на базе Neovim, упакованное в Docker-контейнер. Основная цель — предоставить комфортную среду разработки с минимальными усилиями по настройке, сохраняя при этом портативность и воспроизводимость окружения на любой машине.

## Целевая аудитория

- Разработчики, переходящие с IDE (PHPStorm, WebStorm, VSCode) на Vim/Neovim
- Разработчики, желающие иметь портативное окружение разработки
- Разработчики, работающие на нескольких машинах и желающие иметь идентичную настройку

## Основные возможности

### 🐳 Контейнеризация
- Полностью автономное окружение в Docker-контейнере
- Запуск через удобный bash-скрипт `bin/neovim`
- Возможность создания символической ссылки: `ln -s /path/to/bin/neovim /usr/local/bin/vim`
- Опциональная поддержка запуска вне Docker (нативный режим)
- Изоляция зависимостей и версий инструментов

### ⌨️ Настройка и управление
- **Гибкая система горячих клавиш**: полностью настраиваемые биндинги для всех действий
- **Поддержка мультиязычных раскладок**: хоткеи работают как на русской, так и на английской раскладке клавиатуры
- **Интерактивный хелпер**: встроенная справка по всем доступным хоткеям и командам
- **Темы оформления**: поддержка популярных цветовых схем с простым переключением

### 🎨 Визуальное оформление
- Решение проблем с цветами и шрифтами в терминале
- Правильная работа с различными эмуляторами терминала
- Поддержка Nerd Fonts и иконок
- Настройка отображения для корректной работы со всеми элементами интерфейса

### 💻 Языковая поддержка и LSP
Интегрированная поддержка Language Server Protocol для:
- **JavaScript/TypeScript** — полная поддержка современного JS/TS
- **Vue.js** — работа с SFC (Single File Components)
- **PHP** — включая современные стандарты PSR
- **Bun** — поддержка нового JavaScript runtime
- **NestJS** — TypeScript фреймворк
- **HTML/CSS/SCSS** — полноценный автокомплит и валидация
- Легкое добавление поддержки новых языков

### 🔍 Навигация и поиск
- **Переход по определениям** (Go to Definition)
- **Поиск использований** (Find References)
- **Поиск по проекту** — быстрый fuzzy search
- **Поиск по текущему файлу** — инкрементальный поиск
- **Поиск по символам** — навигация по классам, функциям, переменным
- **Breadcrumbs** — отображение текущей позиции в коде

### 🧠 Автодополнение
- Интеллектуальный автокомплит на базе LSP
- **GitHub Copilot** — интеграция AI-ассистента для генерации кода
- Snippet-ы для часто используемых конструкций
- Контекстные подсказки и документация
- Специальный автокомплит для CSS/SCSS/HTML/Vue с поддержкой классов и свойств

### 🪟 Работа с файлами и вкладками
- Удобная система вкладок (tabs/buffers)
- Файловый менеджер (file explorer)
- Быстрое переключение между файлами
- Split-окна (вертикальные и горизонтальные)
- Сохранение сессий работы

### 🐛 Отладка
- **Xdebug** интеграция для PHP
- DAP (Debug Adapter Protocol) поддержка
- Точки останова (breakpoints)
- Просмотр переменных и стека вызовов
- Step debugging (шаг за шагом)

### 🔧 Git интеграция
- **Git Blame** — отображение информации об авторе прямо на строке кода
- Просмотр изменений (diff)
- Навигация по изменениям
- Интеграция с различными Git-провайдерами
- Визуальное отображение статуса файлов

## Установка

### Требования
- Docker (версия 20.10 или выше)
- Docker Compose (опционально, для удобства)
- Git

### Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd neovim-docker-ide
```

2. Соберите Docker образ:
```bash
cd docker
docker-compose build
```

3. Создайте символическую ссылку для удобного запуска:
```bash
sudo ln -s $(pwd)/bin/neovim /usr/local/bin/vim
# или
sudo ln -s $(pwd)/bin/neovim /usr/local/bin/nvim
```

4. Запустите Neovim:
```bash
vim /path/to/your/project
```

## Использование

### Запуск

**С использованием wrapper-скрипта:**
```bash
./bin/neovim [файл или директория]
```

**Напрямую через Docker:**
```bash
docker-compose run --rm neovim [файл или директория]
```

### Первый запуск

При первом запуске автоматически произойдет:
1. Установка менеджера плагинов (lazy.nvim)
2. Загрузка и установка всех плагинов
3. Установка Language Servers
4. Настройка окружения

Это может занять 2-3 минуты.

### Основные горячие клавиши

> Полный список горячих клавиш доступен в файле [docs/KEYBINDINGS.md](docs/KEYBINDINGS.md)

**Лидер-клавиша:** `Space` (пробел)

#### Общие
- `<Leader>h` — открыть интерактивный хелпер с хоткеями
- `<Leader>ff` — поиск файлов в проекте
- `<Leader>fg` — поиск текста в проекте (grep)
- `<Leader>fb` — список открытых буферов

#### Навигация
- `gd` — перейти к определению
- `gr` — найти все использования
- `K` — показать документацию
- `<Leader>e` — открыть файловый менеджер

#### Работа с вкладками
- `<Leader>tn` — новая вкладка
- `<Leader>tc` — закрыть вкладку
- `gt` / `gT` — следующая/предыдущая вкладка

#### Git
- `<Leader>gb` — git blame текущей строки
- `<Leader>gd` — показать diff
- `<Leader>gs` — git status

#### Отладка
- `<F5>` — начать/продолжить отладку
- `<F9>` — установить breakpoint
- `<F10>` — step over
- `<F11>` — step into

## Настройка

### Изменение горячих клавиш
Редактируйте файл `nvim/lua/keymaps/init.lua`:
```lua
-- Пример изменения биндинга
vim.keymap.set('n', '<Leader>ff', '<cmd>Telescope find_files<cr>', { desc = 'Find files' })
```

### Добавление новых тем
1. Добавьте тему в `nvim/lua/plugins/themes.lua`
2. Активируйте в `nvim/lua/config/appearance.lua`:
```lua
vim.cmd('colorscheme your-theme-name')
```

### Настройка Language Server
Добавьте конфигурацию в `nvim/lua/lsp/servers/`:
```lua
-- nvim/lua/lsp/servers/your-language.lua
return {
  cmd = { "your-lsp-binary" },
  settings = {
    -- настройки LSP
  }
}
```

### Режим работы вне Docker (нативный)
Для запуска без Docker:
1. Установите Neovim (версия 0.9+)
2. Скопируйте конфигурацию: `cp -r nvim ~/.config/nvim`
3. Установите зависимости согласно `docs/NATIVE_SETUP.md`

## Решение проблем

### Проблемы с раскладкой клавиатуры
Все хоткеи настроены для работы с любой раскладкой. Если возникают проблемы, проверьте:
- Настройки `langmap` в `nvim/lua/config/keyboard.lua`
- Переключение раскладки на уровне системы

### Проблемы с цветами
Убедитесь, что ваш терминал поддерживает True Color:
```bash
echo $TERM
# Должно быть что-то вроде: xterm-256color или screen-256color
```

### Проблемы с шрифтами
Установите Nerd Font для корректного отображения иконок:
- [JetBrains Mono Nerd Font](https://www.nerdfonts.com/)
- [Fira Code Nerd Font](https://www.nerdfonts.com/)

Подробнее в [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)

## Расширение функциональности

### Добавление нового плагина
1. Добавьте плагин в `nvim/lua/plugins/`:
```lua
return {
  'author/plugin-name',
  config = function()
    -- настройка плагина
  end
}
```
2. Перезапустите Neovim или выполните `:Lazy sync`

### Добавление поддержки нового языка
1. Найдите нужный Language Server на [LSP Config](https://github.com/neovim/nvim-lspconfig/blob/master/doc/server_configurations.md)
2. Добавьте конфигурацию в `nvim/lua/lsp/servers/`
3. Зарегистрируйте в `nvim/lua/lsp/init.lua`
